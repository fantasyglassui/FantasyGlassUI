Tutoriel 2

Planifier avec un ami

Un seul itinéraire pour deux : les mêmes quêtes dans le même ordre, pour vous et un ami.

  1. Vérifiez que vous pouvez tous les deux

    Il vous faut tous les deux Fantasy Glass UI 13.0 ou plus récent, et pas plus de 6 niveaux d'écart. Vous devez être amis dans le jeu ou sur Battle.net, dans la même guilde ou dans le même groupe : personne d'autre ne peut vous le demander.

  2. Ciblez votre ami

    Ciblez-le, ou soyez en groupe rien que tous les deux. Vous pouvez aussi taper /fgui guide duo suivi de son nom.

  3. Demandez-lui

    Appuyez sur Planifier avec un ami dans la fenêtre du planificateur, sous « Avec d'autres », ou dans le menu du panneau du guide.

  4. Votre ami répond

    Il voit votre question avec Planifier ensemble et Non merci, et a 30 secondes pour répondre. Si la lecture à voix haute est activée, la question lui est lue.

  5. Jouez ensemble

    Vous planifiez l'itinéraire, et votre ami suit les mêmes quêtes dans le même ordre. Votre panneau montre où en est votre ami et vous dit quand l'attendre.

  6. Arrêtez ensemble

    Appuyez sur Arrêter de planifier ensemble dans le menu du panneau du guide, ou tapez /fgui guide duo off. Se déconnecter ou recharger l'interface y met fin aussi.

Bon à savoir

  • La planification commune se met en pause dans une instance et reprend à la sortie.
  • Si votre ami n'a pas Questie, l'itinéraire planifie les quêtes que vous avez tous les deux.
  • Les deux add-ons ne parlent qu'entre eux, par chuchotement. Rien n'est écrit dans les canaux publics.
  • Vous préférez ne pas être sollicité ? Désactivez Laisser des amis proposer de planifier avec vous dans la fenêtre du planificateur.
