Carte du monde

Kalimdor et les Royaumes de l'Est côte à côte, faits des cartes de zone du jeu. Faites glisser pour vous déplacer ; faites défiler, pincez ou utilisez les boutons pour zoomer.

La carte a besoin de JavaScript pour s'afficher.

Aucun lieu n'est encore marqué sur la carte.

Aide aux repères

Cliquez sur la carte pour lire les coordonnées d'un endroit : des pixels depuis le coin supérieur gauche de la carte entière, comme markers.json les attend.
