사용법 3

휴대폰에서 계획 페이지 보기

게임에서 계획 코드를 복사해 휴대폰에서 경로를 따라가며 단계를 체크하세요.

  1. 계획된 경로 따라가기

    ‘계획 공유’는 플래너가 만들어 준 경로에 쓰는 기능이니 먼저 경로를 계획하세요.

  2. ‘계획 공유’ 누르기

    플래너 창의 ‘다른 플레이어와’ 아래와 안내서 패널 메뉴에 있습니다. 계획 코드가 이미 선택된 상자가 열리면 Ctrl+C를 눌러 복사하세요.

  3. 휴대폰으로 코드 보내기

    메모나 나에게 보내는 메시지 등 휴대폰에서 읽을 수 있는 곳에 붙여 넣으세요.

  4. 계획 페이지 열기

    휴대폰에서 fantasyglassui.com/plan에 들어가 상자에 코드를 붙여 넣으세요.

  5. 진행하면서 체크하기

    페이지에는 경험치와 시간, 레벨, 비행과 배편, 번호 매긴 들를 곳이 있는 지역별 작은 지도, 체크 상자가 달린 모든 단계가 나옵니다.

알아 두면 좋은 점

  • 체크 표시는 그 브라우저에 그 코드별로 남습니다. ‘체크 지우기’로 처음부터 다시 시작합니다.
  • 코드를 붙여 넣으면 페이지 주소에 코드가 담깁니다. 페이지를 즐겨찾기하거나 코드 대신 주소를 휴대폰으로 보내세요.
  • 페이지는 휴대폰에서 코드를 읽고 아무 데도 보내지 않습니다. 사이트로도 보내지 않습니다: 코드는 주소의 # 뒤에 있고, 브라우저는 그 부분을 밖으로 보내지 않습니다.
  • 코드 하나에 최대 60단계가 담깁니다. 페이지는 저절로 바뀌지 않으니, 게임에서 ‘다시 계획’한 뒤에는 경로를 다시 공유하세요.
  • 페이지는 9개 언어를 지원합니다: 위에서 내 언어를 고르세요.
