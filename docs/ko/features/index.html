    Fantasy Glass UI, ElvUI, 아니면 게임 기본?

    셋 다 좋은 선택입니다. 여기에는 각각이 무엇인지, 그리고 확인할 수 있는 것만 적었습니다. Fantasy Glass UI는 자체 코드와 안내서로, 나머지 둘은 누구나 직접 볼 수 있는 것으로요.

    옮겨 오기

    ElvUI, Tukui, RealUI, GW2 UI 또는 게임 기본 인터페이스를 쓰다 오셨나요? 설정의 마지막 단계에서 한 번만 누르면 프레임이 그 인터페이스와 비슷한 배치로 놓입니다.

    설정 단계별 안내

    ElvUI를 계속 쓴다면

    ElvUI가 켜져 있으면 Fantasy Glass UI는 ElvUI가 그리는 부분을 양보합니다: 유닛·공격대 프레임, 행동 단축바, 가방과 은행, 이름표, 미니맵, 채팅, 툴팁과 몇몇 바. 퀘스트 안내서와 골드 도우미를 비롯한 나머지는 그대로 작동합니다. /fgui conflicts off를 쓰면 자체 부분을 유지합니다.

    게임 기본을 계속 쓴다면

    모든 부분에 따로 스위치가 있습니다. 설정에서 게임 기본 프레임의 모양만 바꿀 수도 있고, 게임 프레임은 그대로 두고 가방과 이름표만 쓸 수도 있습니다.

    ElvUI는 별도의 제작자가 만들며 Fantasy Glass UI와는 관계가 없습니다. ElvUI와 게임 기본 인터페이스에 대해서는 누구나 볼 수 있는 것만 적었습니다. 오래된 내용이 있으면 Discord로 알려 주세요. 바로잡겠습니다.
