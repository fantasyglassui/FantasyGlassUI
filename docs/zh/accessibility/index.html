辅助功能

Fantasy Glass UI 在界面的每个部分都内置了辅助功能：适合各类色觉的配色、高对比度主题、易读字体、字幕、朗读、安全闪烁和单手按键。全部免费，每一项都可以开关。

游戏中：/fgui access 打开辅助功能设置，首次设置里也有“舒适”这一步。 版本 13.0.1.

色觉低视力朗读听觉闪烁与动态手与按键路线规划器与金币专注与平静分享

色觉

适用于红绿或蓝黄色盲，或完全看不到颜色的情况。

  • 适合你色觉的配色. 红绿（蓝和橙）、蓝黄（青、粉和红），或完全不用颜色，由亮度和标记表达含义。
  • 颜色之外还有标记. 减益效果带字母，物品品质带圆点，姓名板上的仇恨带标记（快丢失时是“!”，丢失时是“!!”）。

低视力

让屏幕更容易看清。

  • 高对比度主题. 纯黑面板、白色文字和最醒目的边框，玻璃、奇幻、星空三个系列都有。一个按钮就能选出你所用系列的那一款。
  • 为阅读而生的字体. 易读字体（为低视力设计的 Atkinson Hyperlegible）和阅读障碍友好字体（OpenDyslexic）。每个字母更粗的描边，以及屏幕中央消息后的深色衬底。
  • 更大的文字和界面. 独立于游戏的文字大小和界面缩放。
  • 目标周围的光环. 在目标的姓名板外加 1 到 8 像素的粗描边，让它在人群中一眼可见。鼠标指针周围也可以加光环。

朗读

为盲人和低视力玩家，以及更喜欢听的人。使用游戏自带的语音。

  • 对话和任务打开时朗读. NPC 说的话和提供的选项、任务的文本、进度和奖励，以及书籍和信件。关闭窗口时朗读停止。
  • 你指着的东西. 鼠标停在某处时，会朗读它的提示。（游戏自带的屏幕旁白只在登录前有效。）
  • 一键朗读. 一个键可朗读鼠标下的提示、正在看的任务或最近一条密语。
  • 语音提醒. 就位确认、密语、缺少的增益、失控和你自己的提醒，都会读出来。

听觉

为聋人和听障玩家，以及关掉声音玩的人。

  • 声音字幕. 就位确认、密语、排队、邀请、决斗、复活、召唤、首领表情、团队警报、拾取掷骰、仇恨警告和你自己的提醒，都会在屏幕上以带类型标记的一行文字显示。

闪烁与动态

为对闪光或动态敏感的玩家。

  • 安全闪烁. 任何东西每秒闪烁不超过三次，闪光柔和，脉动的警告保持静止，游戏的低生命红色闪屏也会关闭。
  • 减少动画. 没有淡入淡出、脉动、滑动的条或镜头漂移：一切即时出现和变化。
  • 静止的星空. 星空主题保留星星但保持静止：没有闪烁也没有流星，其他部分照常动。

手与按键

为单手游戏或只用键盘的玩家。

  • 单手按键. 一个按钮把移动、跳跃、选目标、互动和前几个动作键放到 W、A、S、D 周围供左手使用，或全部放到数字小键盘供右手使用。另一个按钮把所有按键恢复原样。
  • 用键盘操作游戏窗口. 打开 NPC 对话、任务、商人、邮箱、拾取、训练师、飞行管理员或询问框时，Tab 在按钮之间移动，Enter 按下，用光环显示当前位置，愿意的话每个选项都会读出来。
  • 用键盘操作设置. Tab 和方向键在设置之间移动，空格键切换，左右键移动滑块。
  • 更大的控件. 设置中的开关更大，“点两次”的按钮会等第二次点击十秒钟。

路线规划器与金币

13.0 新功能：用适合你的方式跟随路线、赚取金币。

  • 用键盘操作规划器. 打开用键盘浏览设置后，Tab 和方向键可以在规划器窗口中移动，空格或 Enter 按下按钮或开关，左右键切换选项或调节滑块。战斗中所有按键都交还给游戏。
  • 路线快捷键. 下一步、跳过步骤和重新规划都可以在游戏的按键设置中各绑定一个键，不用鼠标也能跟随路线。
  • 朗读路线. 打开朗读对话和任务后，每到一个新步骤都会读出来。首次导览和好友发来的一起规划邀请也会朗读。
  • 适合你眼睛的颜色. 规划器的列表颜色取自你的主题和色觉设置。出售建议会用文字写出现在出售、暂留或卖给商人，颜色从来不是唯一的提示。
  • 更大的按钮. 打开设置中使用更大的控件后，规划器窗口、指南面板及其菜单的按钮也会更高。
  • 可跳过的导览. 第一次会有四页简短说明介绍规划器。“跳过”立即关闭，左、右、Enter 和 Esc 键也能用，规划器如何工作可以再次打开。
  • 按你的方式使用箭头. 规划器窗口里的停止会收起路线和箭头，直到你再次规划。/fgui move 可以移动箭头，也可以改用 TomTom 的箭头，打开减少动画后到达时箭头不会脉动。
  • 休息. 打开在适合停下的地方提醒我休息后，连续游戏一段时间（1 到 3 小时，由你选择）后到达适合停下的地方时，路线会提醒你。

专注与平静

让屏幕更安静。

  • 平静模式. 一次只显示一条通知，停留十五秒，点击即可收起，消息也会停留更久。
  • 提示前稍等. 鼠标停留片刻才显示提示，扫过屏幕时不会一个接一个地弹出。

分享

帮朋友设置，或设置新角色时用。

  • 一行文字. 把所有辅助功能设置变成一行文字，可以复制、保存或给别人；粘贴回来即可一次全部应用。
  • 设置中的“舒适”步骤. 首次设置中有视觉、听觉和平静这一步，开始游戏前就准备好。

（暂时）做不到的事

它不是屏幕阅读器：朗读涵盖对话、任务、书籍、提示、密语和游戏主要窗口的按钮，但不是每个窗口的每个部分。 金币窗口还没有自己的快捷键，也不会朗读。 两种易读字体只含西欧字母。朗读使用你的电脑提供给游戏的语音。 欢迎到 Discord 提出想法和问题。
