Azeroth

世界地图

卡利姆多和东部王国并排，取自游戏自带的区域地图。拖动来移动；滚动、双指缩放或用按钮来缩放。

地图需要 JavaScript 才能显示。

地图上还没有标记任何地点。

标记助手

点击地图即可读出某处的坐标：从整张地图左上角起算的像素，正是 markers.json 所用的格式。
