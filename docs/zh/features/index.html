    转过来

    从 ElvUI、Tukui、RealUI、GW2 UI 或游戏自带界面转过来？在设置向导的最后一步，点一下就能把框体排成类似那套界面的布局。

    设置向导，一步一步

    保留 ElvUI

    加载 ElvUI 时，Fantasy Glass UI 会让出 ElvUI 绘制的部分：单位和团队框体、动作条、背包和银行、姓名板、小地图、聊天、鼠标提示以及几条进度条。其余部分，包括任务指南和金币顾问，照常工作。/fgui conflicts off 则让它保留自己的部分。

    保留游戏自带界面

    每个部分都有自己的开关。设置向导也可以只给游戏自带的框体换个外观，你也可以保留游戏的框体，只用比如背包和姓名板。

    ElvUI 由其自己的作者制作，与 Fantasy Glass UI 无关。这里关于它和游戏自带界面的内容，只写任何人都能看到的；如有过时之处，请在 Discord 告诉我们，我们会改正。
