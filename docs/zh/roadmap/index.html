进行中

计划中的地下城

地下城能给很多经验，所以规划器也会把它们算进去，单人玩家也一样。它会把一个地下城和你附近的任务区域作比较，算上找队伍、赶路和通关的时间，只有更划算时才会安排。这样地下城就成了路线中真正的步骤。

大约 15 分钟还没找到队伍？“跳过这个地下城”会在本次游戏中不带它规划剩下的路线。和好友一起规划时，你们已经是五人中的两人。规划器窗口里的“路线中加入地下城”开关可以关闭它，而“保留我的路线”从不会自行加入地下城。地下城规划需要 Questie。

进行中

按时完成职业任务

职业任务不会再让你措手不及、远在世界另一头。提前一两级，你会收到提醒，指南面板和聊天里各一次。到了它的等级，路线会先去任务的起点，再去其他远处的地方，并先完成它需要的前置任务。

它遵循你的“规划职业任务”设置；在你“不再推荐此任务”列表里的任务不会提醒。

进行中

向众多玩家学习

如果你愿意，插件会记录你的等级和任务各花了多久，不含任何名字，并能把它变成可分享的代码。玩家发来的代码会帮助为所有人改进规划器的时间估算。在你开启之前它是关闭的，也绝不会自行发送任何内容。

进行中

速度预算

你看不到这一项，这正是重点。计时测试会测量插件自身的工作，一旦某次改动让某部分明显变慢就会失败，这样插件就不会一点点变得笨重。每个上限都留有充足余量，只有真正变慢时测试才会失败。

进行中

崩溃报告，你愿意才发

出错时，插件可以保留一份简短报告：出了什么问题、在哪里、哪个版本，不含任何名字。通过“报告问题”可以复制它，分享到 Discord 或 GitHub。在你开启之前它是关闭的，也绝不会自行发送任何内容。

进行中

每次游戏补丁后的检查

WoW: Forever 更新后首次登录时，插件会检查游戏是否仍提供它所用的一切。若缺少某项，它只关闭相应部分并告诉你是哪一部分，而不是弹出错误。

进行中

存档数据整理与备份

每日备份和更新前的备份也会保存规划器、金币和指南的记录，恢复时它们会和其他内容一起回来。拍卖价格不会备份，因为下次扫描就会重新得到，这样存档文件就能保持小巧。

任何东西都不会被自动删除。更新后第一次登录时，新内容里会有一行告诉你这件事。

进行中

测试版渠道

在 CurseForge 上提供抢先测试版，给想先试用的玩家。在 CurseForge 应用中把 Fantasy Glass UI 设为 Beta 即可获取，改回 Release 即停止。测试版会在登录时说明，“报告问题”中也会注明。
