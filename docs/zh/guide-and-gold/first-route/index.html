教程 1

你的第一条路线

打开路线规划器，一步步跟随你的第一条任务路线。

  1. 想要的话加装 Questie

    没有 Questie 时，规划器按任务日志里的任务规划。同时加载 Questie 插件时，它能规划你等级的所有任务。 Questie 带来什么

  2. 打开规划器

    在聊天框输入 /fgui plan。第一次会有四页的简短导览介绍规划器：读一读，或按“跳过”。

  3. 选择你的玩法

    在规划器窗口里，风格可选速度或剧情，你能玩多久？设定时间，组队任务决定是否规划组队任务。全部保持原样也可以。

  4. 按“规划我的路线”

    规划器算出路线并开始跟随。指南面板显示第一步，屏幕上方附近的箭头指明方向。

  5. 跟随步骤

    接任务、做任务、交任务时，步骤会自动勾选。按 > 跳过一步，按 < 退回一步，按重新规划从你现在的位置重新规划。

  6. 右键点击步骤查看更多

    为什么选这个?说明这一步的价值。暂时跳过此任务在本次游戏中不再安排它，不再推荐此任务则永久排除。

  7. 随时停止

    规划器窗口里的停止会收起路线和箭头。想要时按规划我的路线再做一条新的。

小贴士

  • 升级、交任务或经过读取画面时，规划器会自动重新规划。打开保留我的路线后，只有按按钮时才会规划。
  • 下一步、跳过步骤和重新规划都可以在游戏的按键设置中各绑定一个键。
  • 跟随路线时登录游戏，会有一行提示你上次到了哪里、接下来做什么。
  • 打开在适合停下的地方提醒我休息，长时间游戏后到达适合停下的地方时，面板会提醒你。
