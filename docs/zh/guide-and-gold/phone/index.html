教程 3

在手机上使用计划页面

在游戏中复制计划代码，在手机上跟随路线并勾选步骤。

  1. 跟随一条规划好的路线

    “分享计划”针对规划器为你做的路线，所以先规划一条。

  2. 按“分享计划”

    它在规划器窗口的“与他人一起”下，也在指南面板菜单里。会弹出一个已选中计划代码的框：按 Ctrl+C 复制。

  3. 把代码发到手机

    把它粘贴到笔记、发给自己的消息，或任何手机能看到的地方。

  4. 打开计划页面

    在手机上打开 fantasyglassui.com/plan，把代码粘贴到框里。

  5. 边玩边勾选

    页面显示经验和时间、等级、飞行和航渡次数、每个区域带编号停靠点的小地图，以及每一步的勾选框。

小贴士

  • 勾选只保存在该浏览器中，按代码区分。“清除勾选”可以重新开始。
  • 粘贴代码后，页面地址里就带上了它。把页面加入书签，或者把地址代替代码发到手机。
  • 页面在你的手机上读取代码，不向任何地方发送内容。代码也从不会发给网站：它位于地址里的 # 之后，浏览器不会把这部分发出去。
  • 一个代码最多包含 60 步。页面不会自己更新：在游戏里重新规划后，请再次分享路线。
  • 页面支持九种语言：在顶部选择你的语言。
