13.0 新功能

指南与金币

Fantasy Glass UI 内置的两个助手：在你升级时安排任务的路线规划器，以及列出值得花时间去做的事的“赚金方法”。两者都免费。规划器在你使用时加载，赚金点子在你使用或打开拍卖行时加载。

规划你的第一条路线 打开计划页面

分六步浏览本页，按你自己的节奏来。

升级

路线规划器

它为你的等级规划任务路线：接哪些、按什么顺序，以及何时飞行、训练或交任务。你玩的时候它会重新规划，路线始终跟得上你。

一步一步

一个小面板显示当前步骤，箭头指明方向。完成步骤时会自动勾选。

你的节奏

速度、安全和剧情三个滑块决定路线的侧重。说出你能玩多久，路线就只安排能完成的内容，并在适合停下的地方结束。

沿途停靠

新的飞行点、每两级一次的职业训练师、背包快满时的商人、邮件，以及 40 级起的坐骑提醒。每种停靠都可以关闭。

地图上

世界地图上标出带编号的路线停靠点及连线，并在每个有任务的区域做标记，经验来得越快的地方越亮。

与好友一起

两人一条路线：同样的任务，同样的顺序。面板会显示好友落后多少。

在手机上

“分享计划”会把路线变成一段代码。把它粘贴到计划页面，就能在手机上查看路线并勾选步骤。

用 /fgui plan、设置中“指南”标签页里的规划我的路线，或指南面板上的“规划”按钮打开。第一次会有四页的简短导览加以说明，规划器窗口里的规划器如何工作可以再次打开它。

可选

Questie 是可选的

规划器可以独立工作。同时加载 Questie 插件时，它对世界了解得多得多。

没有 Questie 时

  • 它规划你任务日志里已有的任务。
  • 商人和邮箱只限你去过的。
  • 草药和矿石只限你亲自采集过的。

有 Questie 时

  • 你等级的所有任务，不只日志里的，还有谁在哪里发布。
  • 旅店、训练师、商人和邮箱，包括你还没找到的。
  • 任务用完时可以刷怪的地点，以及“完成区域”目标，它会规划该区域剩下的每个任务。
  • 在“赚金方法”中：哪些怪物会掉落你任务所需的物品。

Questie 仍在加载时，规划器会等待，半分钟后改用你的任务日志规划。如果 Questie 的变化让规划器无法读取，它会说明，并按任务日志规划。

金币

赚金方法

一个窗口按优劣列出赚金方法，依据你见过的一切：你所在拍卖行的价格、商人的收购价、你拾取过的怪物、采集过的草药和矿石，以及你会的配方。

立即可做

顶部是几件马上能做的事，比如卖掉背包里的东西。

各种点子

卖掉背包里的东西，以及你上次看到的银行物品；把垃圾卖给商人；从商人处买进在拍卖行能卖更高价的东西；有利可图的制造；采集路线；值得击杀的怪物；以及地下城掉落。

按你的方式排序

每个点子都会说明能赚多少、有多轻松、有多稳妥，以及价格有多新。“最多金币”“轻松赚钱”“稳妥”可以给列表排序，也可以自己调整每小时金币、轻松度和安全三个滑块。

为目标攒钱

输入一个金额，或选择“40级骑术”或“60级史诗骑术”，每个点子都会显示达成目标需要多久。

前往

“前往”会用规划器的指引带你过去。你的升级路线会暂停，旅程结束后恢复。

在拍卖行

在拍卖行旁边，“此处赚金点子”会列出当场值得做的事。打开拍卖行时会加载它；在设置的 背包与物品 › 金币与刷取 中，拍卖行旁的赚金点子 可以关闭它。

可以在规划器窗口或指南面板菜单中点赚金方法，输入 /fgui guide gold，或按住 Ctrl 点击小地图按钮打开。它从不替你购买、上架或制造：每一次点击都由你自己来。

在拍卖行

价格与出售建议

赚金点子的好坏取决于价格。按一下“扫描价格”就能读取整个拍卖行，之后物品提示会告诉你该怎么处理它。

  • 现在出售 今天明显高于平常价格
  • 暂留 今天便宜：等更好的价格
  • 卖给商人 商人给价差不多，或者没人出售

分步说明

使用教程

  1. 1

    你的第一条路线

    打开路线规划器，一步步跟随你的第一条任务路线。

  2. 2

    与好友一起规划

    两人一条路线：你和好友按同样的顺序做同样的任务。

  3. 3

    在手机上使用计划页面

    在游戏中复制计划代码，在手机上跟随路线并勾选步骤。

  4. 4

    你的第一次价格扫描

    用“扫描价格”一次读取所有拍卖，让提示、出售建议和赚金点子都有价格可依。

  5. 5

    看懂出售建议

    提示和背包上的“现在出售”“暂留”“卖给商人”是什么意思，以及何时出现。

任何屏幕

计划页面

粘贴游戏里的计划代码，路线就会显示在任何屏幕上：预计的经验和时间、每个区域带编号停靠点的小地图，以及可以勾选的每一步。手机也能用，你粘贴的内容不会离开浏览器。

隐私

哪些内容保持私密

  • 与好友一起规划只通过密语和好友的插件通信，并且总会先征求对方同意。不会在公共频道发送任何内容。
  • 计划代码包含步骤、区域、等级和时间，不含角色名或服务器名。
  • 计划页面在你的浏览器里读取代码，不向任何地方发送内容。你的勾选只保存在该浏览器中。
  • “赚金方法”只依据你自己角色见过的内容，不分享任何东西。

  1. 面板显示什么

    一个小面板显示你当前的步骤，完成后会自动勾掉。按 > 跳过一个步骤，按“重新规划”从你现在的位置重新规划，右键点击步骤可查看更多选项。

  2. 箭头

    箭头指向你当前步骤的地点。步骤在另一张地图上时，它会指向前往那里的下一段路，比如飞行管理员或码头。加载了 TomTom 时，也可以改用 TomTom 的箭头。

  3. 规划我的路线

    设置中“指南”标签页里的规划我的路线会从你所在的位置为你的等级规划一条任务路线，并开始带你走。

  4. 规划器窗口

    /fgui plan 或指南面板上的“规划”会打开规划器窗口：顶部是你正在跟随的内容，下面是它规划内容的每项设置，例如速度、安全和剧情滑块，以及你能玩多久。

  5. 金币窗口

    “赚金方法”会列出适合这个角色的点子，最好的排在前面。每个点子都有“前往”，它会规划行程并放到指南面板上。

  6. 在任何屏幕上查看你的路线

    规划器窗口里的分享计划会把路线变成一段代码。在计划页面上，这段代码会变成每个区域的地图和可以勾选的步骤列表。下面就是一个示例。
