开始使用

从下载到拥有自己的外观，大约五分钟。

版本 13.0.1·更新于 2026-11-27·已对照 WoW: Forever 1.60.1 (70938) 检查·源代码

  1. 1

    安装

    用 CurseForge 应用安装，或下载 zip，把里面的每个文件夹并排放进 World of Warcraft/_forever_/Interface/AddOns。

    手动安装时：每个文件夹的 .toc 文件要直接位于该文件夹内，而不是再深一层。在游戏的插件列表中全部保持启用；有些只在需要时才加载。

    在 CurseForge 下载
  2. 2

    登录并跟着设置向导走

    第一次登录时，设置向导会自动打开。它用四个简短步骤问你要它接管多少、你怎么玩、喜欢哪种外观，然后给你一个起步的布局。

    从其他界面转过来的？ 在最后一步，点一下就能把框体排成类似 ElvUI 或 Tukui、RealUI、GW2 UI、游戏自带界面的布局。 它们如何比较

    /fgui setup 随时可以重新运行。新角色会沿用你主角色的设置，并按其职业调整。

  3. 3

    选一款主题

    输入 /fgui，打开外观与主题。选一个系列（玻璃、奇幻或星空），再选其中一款主题：整个屏幕都会跟着变。换到另一个系列要在 /reload 之后才完成。

    先在本站试试

  4. 4

    接下来试试这三件事

    • 规划路线：在 /fgui 中打开“指南”标签页，按规划我的路线。
    • 了解东西值多少：在拍卖行按扫描价格，然后把鼠标指向背包里的任何物品。
    • 随意移动：输入 /fgui move，拖动把手即可。/fgui undo 可撤销一次移动。

发现问题，或者有想法？

来 Discord 聊聊，或在 GitHub 告诉我们。报告问题时最有用的是插件自带的报告：在游戏中打开 /fgui，点击 Report a Problem 并粘贴文字。其他事宜：email-forwarding@fantasyglassui.com。

问题与命令

常见问题

适用于哪个游戏？

WoW Forever（界面版本 16001）。把压缩包里的所有文件夹并排放进 World of Warcraft/_forever_/Interface/AddOns 即可。

能和其他插件一起用吗？

可以。如果你已经在用做同样事情的插件，比如姓名板用 Plater，背包用 Bagnon 或 Baganator，团队框体用 Grid2、VuhDo 或 Cell，Fantasy Glass UI 会让出那一部分，其余照常。输入 /fgui conflicts off 则改用它自己的。

可以只用一部分吗？

可以。/fgui 里每个部分都有自己的开关，比如只保留背包和姓名板，其余交给游戏。

我喜欢方形框体，能用经典外观吗？

可以。在 /fgui 的“框体与动作条”中选择 Classic 代替 Starcut，所有框体、条和按钮都会变回方框形状，任何主题都适用。

对色盲、低视力或听力有帮助吗？

是的，有一整个类别。/fgui access 提供按色觉类型调整的颜色、高对比度主题、适合低视力和阅读障碍的字体、声音字幕、朗读对话、任务和提示、用键盘操作游戏窗口、单手按键、安全闪烁、静止星空和平静模式。它按需求分类的全部功能见辅助功能页面。

会让游戏变卡吗？

关闭的部分完全不会运行。想亲自确认的话，/fgui perf 显示每个部分花费的时间，/fgui perf fight 测量你的下一场战斗，/fgui memory 显示内存占用。

有地方不对劲，怎么恢复？

/fgui undo 撤销上一次移动或缩放，/fgui history 列出你改过的内容，任何一项都能撤销。/fgui reset（输入两次）把配置恢复为初始状态，之前会先备份：/fgui backup 可查看。/fgui safe 会关闭所有功能后重载，用来判断问题是否出在插件。

能把我的设置分享给朋友吗？

可以。/fgui pack 把整个界面（配置、布局、主题、动作条和邮件规则）打包成一段可粘贴的文字，/fgui send <name> layout 则直接发送给装有本插件的其他玩家。

去哪里求助，或者展示我的界面？

在我们的 Discord：到 #fgui-help 提问，在 #show-your-ui 发截图，在 #themes 分享主题代码。那里也有专门报告问题和提建议的频道。

支持哪些语言？

英语、德语、法语、西班牙语、俄语、葡萄牙语、意大利语、韩语和中文。会跟随你的游戏语言。

免费吗？

是的，免费，没有广告，也没有任何需要购买的东西。

常见问题与解决

看起来不对劲，或出现错误

输入 /fgui check 查看正在运行的内容报告。然后打开 /fgui，按报告问题，把得到的文字粘贴到错误报告或 Discord 里。

打不开选项，或界面乱了

/fgui safe 会关闭所有功能并重新加载。在 /fgui 里改好需要的设置，再输入一次 /fgui safe 退出安全模式。

想要找回以前的设置

/fgui backup 列出每次更新前、每天一次以及重置前做的备份。点一个查看如何恢复。/fgui history 逐条列出改动，任何一条都能撤销。

战斗中面板无法移动

游戏不允许任何插件在战斗中移动框体或改变其大小。等战斗结束；战斗中要求的一键穿最佳装备和整理背包，会在结束后自动完成。

在地下城里发送给其他玩家没反应

在地下城和团队副本里，WoW Forever 不允许插件给其他玩家发送消息。在那里发送布局、主题或天赋方案时会提示这一点；到外面再试。

战斗中增益效果看起来不一样

在 WoW Forever 中，战斗时增益和减益效果对插件不可见，所以改为使用重新设计过的游戏自带增益框体。

命令没反应，或者想不起命令

/fgui help 会在可搜索的窗口里列出所有命令。打错时，插件会提示最接近的那条。

“Interface action failed”

输入 /fgui blocked，把它显示的内容附到错误报告里。
