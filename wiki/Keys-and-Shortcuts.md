# Keys and shortcuts

Ways to reach things without typing a command.

## Key bindings

Set these in the game's key bindings: **Esc → Key Bindings → AddOns → Fantasy Glass UI**.

| Binding | What it does |
|---|---|
| Open options | open or close `/fgui` |
| Move panels | turn move mode on or off (`/fgui move`) |
| Keybind mode | hover an action button and press a key (`/fgui bind`) |
| Clean screen (5 seconds) | hide the interface for a screenshot |
| Damage meter drawer | tuck the damage meter away, or bring it out |
| Your characters | all your characters, their level and gold |
| Mount (random favorite) | a random favorite mount, or get off the one you're on |
| Notepad | the notepad |
| Whisper window | the whisper window |
| To-do list | your to-do list |
| Sort bags | sort your bags |
| Key binding sheet (hold) | every action bar and its keys, while you hold the key |
| Quiet mode | hide chat, names and the info bar for screenshots and streaming |
| What's this? (point at a panel) | see which feature made a panel |
| Tools menu | every tool window in one small panel |
| Equip best (put on the upgrades in your bags) | put on the upgrades in your bags |
| Death recap (your last death) | what hit you before you last died |
| Boss note (for your target) | the note for the boss you have targeted; with no target, the list of notes |
| Every command (/fgui help) | the help window |

## The minimap button

| Click | What it does |
|---|---|
| Left-click | the options |
| Right-click | move your panels |
| Shift-click | the Tools menu |
| Drag | move the button around the minimap |

Its tooltip shows the version, and says so when safe mode is on.

## The Tools menu

The **Tools** button on the menu bar (or Shift-click the minimap button) opens a button for every tool window. They are in groups:

- **Groups and raids**
- **Your characters**
- **Bags, gear and trade**
- **People and notes**
- **The world**
- **The add-on itself**

Point at a button to see what it does and the command you could type instead.

## The help window

`/fgui help` lists every command under headings, in a window you can search: `/fgui help bags` shows only the commands about bags. Click a command to put it in the chat box, ready to finish and send. The full list is also on the [Commands](Commands.md) page.

## If you mistype

A mistyped command no longer opens the options. `/fgui equipbets` answers "Did you mean /fgui equipbest?". A word that isn't a command shows the commands that mention it, or points you to `/fgui help`.

## Right-click in the bag window

At a vendor, right-clicking an item in the bag window sells it, gear included. At the bank or guild bank it stores it, in a trade it puts it in the trade, and at the auction house it puts it on the sell page, just as in the game's own bags. Anywhere else, right-click uses or equips the item.

## After a vendor visit

When you close a vendor, one line in chat says what you sold, bought and repaired, and what it all came to. Switch it off with **Vendors: one-line summary** on the Features tab.

## During a fight

The game doesn't allow some things during a fight. If you ask for **Equip best**, **Sort bags** or a **talent build** then, it happens as soon as the fight ends instead of just saying no.

## Windows

- **Close with Escape:** every window the add-on opens closes with **Escape**.
- **Remembered places:** list windows such as help, boss notes and Worth selling stay where you drag them, for all your characters.
- **On screen:** no window can be dragged off the screen.
- **Options tab:** the options open on the tab you used last.
