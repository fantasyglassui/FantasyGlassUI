[[How-to]] 3

[[The plan page on a phone]]

[[Copy a plan code in the game and follow the route on your phone, ticking off the steps.]]

  1. [[Follow a planned route]]

    [[Share plan works on the route the planner made for you, so plan one first.]]

  2. [[Press Share plan]]

    [[It is in the planner window under With others, and in the guide panel's menu. A box opens with the plan code already selected: press Ctrl+C to copy it.]]

  3. [[Send the code to your phone]]

    [[Paste it into a note or a message to yourself, or anywhere your phone can read it.]]

  4. [[Open the plan page]]

    [[On the phone, go to fantasyglassui.com/plan and paste the code into the box.]]

  5. [[Tick as you go]]

    [[The page shows the experience and time, the levels, the flights and crossings, a small map for each zone with numbered stops, and every step with a box to tick.]]

[[Good to know]]

  • [[Your ticks stay in that browser, for that code. Clear the ticks starts again.]]
  • [[Once the code is pasted, the page's address holds it. Bookmark the page, or send its address to your phone in place of the code.]]
  • [[The page reads the code on your phone and sends nothing anywhere. The code is never sent to the site either: it sits after the # in the address, which browsers keep to themselves.]]
  • [[A code holds up to 60 steps. The page does not change by itself: after Plan again in the game, share the route again.]]
  • [[The page speaks nine languages: pick yours at the top.]]
